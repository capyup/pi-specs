# Third Party Notices

## @tintinweb/pi-tasks

Parts of the built-in task manager under `src/tasks/` are adapted from `@tintinweb/pi-tasks` by tintinweb.

- Upstream: https://github.com/tintinweb/pi-tasks
- License: MIT

Earlier versions of `pi-specs` (then named `pi-spec-driven-dev`) vendored this code under `src/tasks/` so spec-driven workflows came with built-in task tracking. As of `0.1.4`, the runtime was removed; `pi-specs` now delegates task tracking to the upstream `@tintinweb/pi-tasks` package, installed alongside it.
